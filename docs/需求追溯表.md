# TravelOn 需求追溯表

## 1. 文档目的

本文档建立 TravelOn 当前需求、业务用例、三层模型、代码模块与测试结果之间的追溯关系，用于检查需求是否完成设计、实现和验证闭环。

追踪主键采用 [业务场景说明](业务场景.md) 中稳定的 `BS-01`～`BS-08`。需求来源以 [需求规格](需求规格.md) 的系统需求、能力需求和合格性规定为准；三层模型分别对应系统级、组件级和对象级设计。

## 5. 覆盖情况与待维护项

- 8 个当前业务场景均已追溯到需求、组件级模型、对象级模型、主要代码模块和测试记录。
- 系统级业务步骤由 [业务场景说明](业务场景.md) 覆盖，8 张系统级顺序图、状态图或活动图位于 [需求规格 §3.25](需求规格.md#325-业务场景系统级模型)，并已在本表逐项链接。
- 当前测试结果均依据 [测试文档](测试文档.md) 标记为“通过”。重新执行测试后，应以最新测试记录覆盖本表结论，并保留失败或阻塞状态，不能只记录最终通过结果。
- 新增需求、业务场景、代码模块或测试用例时，应使用同一 `SYS-*`、`BS-*`、`TC*` 标识更新对应行，避免只在单份文档中新增孤立内容。
