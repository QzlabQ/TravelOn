# 测试文档

## 1. 文档说明

本文档用于记录“旅游服务平台”的测试环境、测试范围、测试用例、测试结果和问题记录。课程提交时可将本文档补充实际测试截图后导出为 PDF，命名为“X组-测试文档.pdf”。

## 2. 测试目标

本次测试目标如下：

1. 验证系统前端页面能正常访问。
2. 验证后端微服务能正常启动并完成服务注册。
3. 验证用户注册、登录、查询、预订、社区等核心功能可正常使用。
4. 验证系统在常见操作下无明显崩溃或页面异常。

## 3. 测试环境

| 项目 | 配置 |
|---|---|
| 操作系统 | macOS / Windows / Linux |
| 浏览器 | Chrome / Edge |
| 前端地址 | http://localhost:53000 |
| 后端网关 | http://localhost:58082 |
| 服务发现 | http://localhost:58010 |
| 数据库 | PostgreSQL、MongoDB |
| 消息队列 | RabbitMQ |
| 部署方式 | Docker Compose + 前端开发服务 / Nginx |

## 4. 测试范围

本次测试覆盖以下模块：

| 模块 | 测试内容 |
|---|---|
| 部署启动 | 后端容器启动、服务注册、前端访问 |
| 用户模块 | 注册、登录、用户信息 |
| 酒店模块 | 酒店查询、酒店详情 |
| 交通模块 | 交通票务查询 |

| AI 行程规划 | 创建会话、生成行程、查看规划结果 |

## 5. 测试方法

本次测试采用手工测试方式，测试人员通过浏览器访问前端页面，模拟真实用户操作，并结合 Docker Compose 状态和服务日志验证后端服务运行情况。

常用检查命令：

```bash
cd travel-api
docker compose ps
docker compose logs --tail=100 gateway
```

## 8. 问题记录

| 编号 | 问题描述 | 影响范围 | 解决方式 | 状态 |
|---|---|---|---|---|
| BUG001 | Docker Hub 镜像拉取较慢 | 后端部署 | 切换可用镜像源或配置镜像加速 | 已解决 |
| BUG002 | 网关根路径返回 404 | 部署验证 | 该现象为正常情况，网关只配置业务路由 | 已确认 |
| BUG003 | AI 行程规划无法生成 | AI 模块 | 检查是否配置外部模型 API Key | 待配置 |

## 9. 测试结论

经过测试，系统前端页面可正常访问，后端服务可通过 Docker Compose 正常启动，核心服务能够完成注册并提供业务路由。用户、酒店、交通、订单、社区等主要功能可按测试用例进行验证。AI 行程规划功能依赖外部 API Key，展示时需要根据实际配置说明测试结果。
