## 3. 用户注册

### 3.1 功能说明

新用户可以通过注册功能创建账号，注册成功后可登录系统并使用订单、社区、个人资料等功能。

### 3.2 操作步骤

1. 打开系统首页。
2. 点击注册入口。
3. 输入用户名、密码等注册信息。
4. 点击提交按钮。
5. 系统提示注册成功后，可返回登录页面。

### 3.3 预期结果

注册成功后，系统保存用户信息，用户可使用该账号登录。

## 4. 用户登录

### 4.1 功能说明

已有账号的用户可以通过登录功能进入系统，登录后可访问个人资料、旅客信息、订单和社区相关功能。

### 4.2 操作步骤

1. 打开登录页面。
2. 输入账号和密码。
3. 点击登录按钮。
4. 登录成功后进入系统主页面。

### 4.3 预期结果

登录成功后，页面显示用户登录状态，用户可继续进行查询、预订和社区操作。

## 5. 酒店查询

### 5.1 功能说明

用户可以根据目的地、入住时间、离店时间、人数等条件查询酒店。

### 5.2 操作步骤

1. 进入酒店查询页面。
2. 选择目的地。
3. 选择入住和离店日期。
4. 设置入住人数。
5. 点击查询按钮。
6. 查看酒店列表。

### 5.3 预期结果

系统返回符合条件的酒店列表，用户可以查看酒店名称、价格、评分等信息。

## 6. 酒店详情查看

### 6.1 功能说明

用户可以进入酒店详情页，查看酒店介绍、房型、价格、评价等信息。

### 6.2 操作步骤

1. 在酒店列表中选择一个酒店。
2. 点击酒店卡片或详情按钮。
3. 进入酒店详情页面。
4. 查看酒店信息和可预订选项。

### 6.3 预期结果

系统展示酒店详情，用户可根据页面信息决定是否预订。

## 7. 交通查询

### 7.1 功能说明

用户可以查询火车、飞机等交通票务信息，用于规划出行方案。

### 7.2 操作步骤

1. 进入交通查询页面。
2. 选择出发地和目的地。
3. 选择出发日期。
4. 点击查询按钮。
5. 查看交通票务结果。

### 7.3 预期结果

系统展示符合条件的交通票务列表，包括出发时间、到达时间、价格等信息。

## 8. 订单预订

### 8.1 功能说明

用户选择酒店或交通产品后，可以创建预订订单。

### 8.2 操作步骤

1. 选择需要预订的酒店或交通产品。

## 9. 支付与退款

### 9.1 功能说明

用户可以对订单进行支付，也可以在满足条件时申请取消或退款。

### 9.2 操作步骤

1. 进入订单详情页面。
2. 点击支付按钮完成支付。
3. 如需取消订单，点击取消或退款相关按钮。
4. 查看订单状态变化。

### 9.3 预期结果

支付成功后订单状态更新；取消或退款成功后，系统显示对应处理结果。

## 10. 社区功能

### 10.1 功能说明

用户可以在社区中浏览帖子、发布内容、查看评论和点赞。

### 10.2 操作步骤

1. 进入社区页面。

### 10.3 预期结果

系统展示帖子列表和详情，用户发布的内容可在社区页面中查看。

## 11. AI 行程规划

### 11.1 功能说明

用户可以输入目的地、出行天数、偏好等信息，由系统生成旅行行程规划。

### 11.2 操作步骤

1. 进入 AI 行程规划页面。
2. 输入目的地、日期、天数和旅行偏好。
3. 点击生成行程。
4. 等待系统返回行程规划结果。
5. 查看每日行程安排。

### 11.3 预期结果

系统生成包含每日景点、交通、住宿或活动建议的行程规划。

说明：如果未配置 AI API Key，AI 规划功能可能无法正常生成结果，展示时可说明该功能依赖外部模型接口。

## 12. 退出登录

### 12.1 功能说明

用户使用完系统后，可以通过退出登录功能结束当前登录状态。

### 12.2 操作步骤

1. 点击用户头像或个人中心入口。
2. 点击退出登录。
3. 系统返回未登录状态。

### 12.3 预期结果

用户登录状态被清除，需要重新登录后才能访问个人相关功能。

## 13. 使用注意事项

1. 使用订单、社区、个人中心等功能前，建议先登录账号。
2. 如果页面数据加载失败，需要确认后端服务是否已启动。
3. 如果远程部署时前端无法请求后端，需要检查服务器安全组和前端 API 地址配置。
4. AI 行程规划功能依赖外部 API Key，未配置时可能无法正常使用。
