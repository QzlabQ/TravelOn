# Historical Travel Sample Sources

The standalone flight, train, and hotel search pages use reproducible historical
sample data. They do not call live supplier inventory APIs. Prices are reference
snapshots for development and demonstration, not quotes for sale.

## Nationwide demo expansion

The verified historical rows below are preserved. The ticket database also
contains deterministic demo rows generated by
`scripts/generate-ticket-offers.py`. These rows connect all 70 supported
capital and popular tourism cities in both directions for flight and train
search. Their station names and distance-based fare tiers are useful for
development coverage, but their generated service numbers, times, and prices
must not be presented as live inventory or exact historical quotes.
